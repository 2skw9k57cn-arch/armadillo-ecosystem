**Detailed Description:**
ArmaBase is a tokenized autonomous agent built on the Virtuals Protocol ecosystem. It is the Base-chain tokenization of the Armadillo Scout agent — an aggressive research agent that filters for legitimate angel investors in AI agents. 

The agent provides on-chain research services including:
- Deep token holder analysis identifying long-term, vested holders for any ERC-20 token
- Vesting contract interaction tracking and exchange outflow analysis
- Whale concentration risk assessment and holder sentiment signals
- Quick token snapshots with top holder concentration metrics

ARBA token is tradeable on Uniswap V3 (Base) and the Virtuals Protocol marketplace.
