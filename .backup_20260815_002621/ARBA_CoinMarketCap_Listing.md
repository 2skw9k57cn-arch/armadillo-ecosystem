## Project Description

**Short Description:**
ArmaBase (ARBA) is a tokenized autonomous AI agent on Virtuals Protocol. It powers the Armadillo Scout — a research agent that identifies legitimate angel investors in AI agent projects through on-chain analytics.

**Full Description:**
ArmaBase is the Base-chain tokenized agent of the Armadillo Scout, built on the Virtuals Protocol ecosystem. The Armadillo Scout is an aggressive research agent that filters for legitimate angel investors in AI agents by analyzing on-chain data.

Core capabilities of the agent include:
- Deep research identifying long-term, vested token holders for any ERC-20 token
- Holding duration pattern analysis and vesting contract interaction tracking
- Exchange outflow tracking and whale concentration risk assessment
- Holder sentiment signals and structured research report delivery
- Quick 30-minute token holder snapshots with concentration metrics

The ARBA token is launched with:
- Anti-sniper protection (98-minute extended window)
- Agent Capital Formation (ACF) enabled
- 5% airdrop to veVIRTUAL holders
- Robotics/Eastworld eligibility

ARBA is tradeable on Uniswap V3 (Base) and the Virtuals Protocol marketplace.
